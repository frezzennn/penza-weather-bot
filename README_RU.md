# Telegram-бот «Погода Пенза»

## Возможности
- Текущая погода в Пензе
- Почасовой прогноз на ближайшие часы
- Прогноз на 7 дней
- Автоматическая сводка каждые 6 часов
- Восход и закат
- Советы по одежде
- Эвристические погодные предупреждения на 24 часа

Источник: Open-Meteo. Координаты Пензы: 53.1959, 45.0183.
Время: Europe/Moscow.

**Важно:** предупреждения рассчитываются по порогам прогноза и не являются официальными оповещениями МЧС.

## Запуск локально
1. Установить Python 3.11 или новее.
2. `pip install -r requirements.txt`
3. Задать переменную окружения `BOT_TOKEN` (токен не публиковать).
4. `python bot.py`

## Размещение на Render
1. Создать приватный GitHub-репозиторий и загрузить содержимое архива.
2. В Render выбрать New > Blueprint и подключить этот репозиторий.
3. В настройках сервиса добавить `BOT_TOKEN` как Secret Environment Variable.
4. Запустить Worker.

Для постоянной работы нужен тариф/план Render, поддерживающий постоянно работающие Background Worker. Бесплатные веб-сервисы, которые засыпают, для такого бота не подходят.

## Команды
- `/start` — подписаться и показать меню
- `/weather` — текущая погода

Подписчики сохраняются в SQLite. Для постоянного хранения базы на Render подключите persistent disk и задайте `DB_PATH` на путь внутри диска.
